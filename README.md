# Habiba Noor - Social Media Portfolio

Static site, same setup as the research portfolio. No build tools: just HTML, CSS and JavaScript.

## Files
- `index.html` - all content
- `style.css` - design (same theme as the research portfolio, plus work sample cards at the bottom)
- `script.js` - mobile menu and scroll animations
- `assets/profile.jpg` - your photo
- `assets/Habiba-Noor-CV.pdf` - your SMM CV
- `assets/samples/sample-1.jpg` to `sample-6.jpg` - your best posts and posters

## Where to edit
| What | Where |
| --- | --- |
| Intro text | `<section class="hero">` |
| Results numbers | `<section id="results">` |
| Work samples | `<section id="work">`, change the image name, title and caption in each `.sample-card` |
| Skills | `<section id="skills">` |
| Colors and fonts | top of `style.css` |

Deploy: create a new GitHub repo, upload these files, then turn on GitHub Pages (Settings > Pages > main branch).
